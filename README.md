# 📇 Cartão Interativo em React

Uma aplicação frontend desenvolvida para consolidar conceitos fundamentais do ecossistema React. O projeto apresenta uma lista de trabalhos de portfólio aplicando a criação de componentes reutilizáveis, passagem de propriedades (props) e renderização condicional baseada em estados dinâmicos.

## ✨ Funcionalidades

- Exibição de trabalhos (como Rotina do Herói e Climapp) em cartões modulares.
- Gerenciamento de estado individual para cada cartão utilizando o hook `useState`.
- Interatividade em tempo real com alteração de texto de botões ("Selecionar" / "Remover seleção").
- Renderização condicional de feedback visual ("Projeto selecionado").

## 🚀 Tecnologias Utilizadas

- **React** 
- **Vite** 
- **JavaScript (JSX)**
- **CSS** (Estilização inline básica)
